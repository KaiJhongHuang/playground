–最大 –

dBFS 是相對於麥克風「滿格」的數字：0 最大、越負越小聲。沒有校正過，不是噪音計的 dB SPL，只適合比較「比剛剛大聲多少」（每 +6 約等於音壓變兩倍）。

語音指令

  • 「切到相機」「打開麥克風」「去 GPS」：切換分頁
  • 「拍照」：自動開相機拍一張
  • 「現在幾點」：唸出時間
  • 「清除」：清掉辨識結果
  • 「停止」：停止聆聽

切到別的分頁時辨識會自動停止，麥克風不會一直開著。iPhone 網頁的語音辨識是借用系統的聽寫功能，需要網路。

語音朗讀 待命

沒聲音的話，先確認沒開靜音模式、音量有開。想要更自然的中文聲音：「設定」→「輔助使用」→「朗讀內容」→「聲音」→「中文」裡下載「加強版」或「高品質」，重開 Safari 後就會出現在清單裡。

Face ID 通行金鑰 示範

⚠️ 這只是示範。網頁從頭到尾讀不到任何臉部資料：Face ID 是 iPhone 自己比對的，網頁只會收到「驗證成功」和一段數位簽章。這裡用 WebAuthn 建立一把綁在這個網站的通行金鑰，再用它驗證。（Touch ID 機型會改成指紋。）
目前狀態

金鑰會存進 iCloud 鑰匙圈。不想留著：打開「密碼」App（iOS 17 以前是「設定」→「密碼」），找 這個網站 刪除。這個示範沒有伺服器，所以不會真的檢查簽章，正式網站會在伺服器端驗證。
